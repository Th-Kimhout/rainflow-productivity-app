## Setup — not yet done

The Supabase CLI is **not installed** on this machine, so none of the following has been run
and **no migration has been applied to the remote project yet.**

### 1. Install the CLI

```bash
brew install supabase/tap/supabase
```

npm global installs are not supported by Supabase. If you would rather not install it,
`npx supabase@latest <cmd>` works for everything below.

### 2. Link and push

```bash
cd /Users/theamkimhout/Kimhout/app
supabase login
supabase link --project-ref twxkbcxudvrwqkkaecks
supabase db push          # applies the 7 migrations above
```

`supabase link` may want to reconcile `config.toml` against the remote project's actual
settings — that file was hand-written rather than generated by `supabase init`, so expect it
to add keys. Accept its version, but **re-check the three `enable_signup` / anonymous
settings survive**.

### 3. Disable signups — do not skip this

RLS is pinned to `app_owner`, but that is only the second layer. Supabase accepts new signups
by default, and the anon key is public in a public repo.

Dashboard → Authentication → Sign In / Providers:

- **Allow new users to sign up** → OFF
- **Allow anonymous sign-ins** → OFF
- Email provider → enabled, **Confirm email** → ON

### 4. Sign in once, then claim ownership

`app_owner` starts empty, and `is_app_owner()` returns false for everyone while it is — so
the database is closed to all API access until you seed it. That is deliberate.

Signups are now off, so create the account from the dashboard: Authentication → Users → Add
user (send an invite to your address). Then, in the SQL editor:

```sql
insert into app_owner (user_id)
select id from auth.users order by created_at limit 1;

-- verify: must return exactly one row, your account
select u.email, o.claimed_at from app_owner o join auth.users u on u.id = o.user_id;
```

### 5. Enable the OTP fallback in the email template

Magic links use PKCE, and the code verifier lives in the **requesting** browser's
localStorage. Request the link on your laptop, open the mail on your phone, and the exchange
fails with an opaque error.

Dashboard → Authentication → Email Templates → Magic Link: include the numeric code alongside
the link, so `/login`'s 6-digit fallback works.

```html
<p>Or enter this code: <strong>{{ .Token }}</strong></p>
```

### 6. Generate types

```bash
supabase gen types typescript --project-id twxkbcxudvrwqkkaecks \
  > packages/data/src/types.ts
```

Re-run after every schema change. `packages/data/src/types.ts` does not exist yet — Phase 1
is the first code that needs it.

## Backups

The free tier has **no point-in-time recovery**, so PRD §7.2's promise is not achievable as
written. The replacement is a client-side JSON export (Phase 9). For a manual dump:

```bash
supabase db dump --project-ref twxkbcxudvrwqkkaecks -f backup.sql
```
